## Стек

- ASP.NET Core MVC (Controllers + Razor Views), не Razor Pages (Razor Pages подключены, но не используются для основных страниц)
- Bootstrap, jQuery, jQuery Validation, AOS, Owl Carousel, Magnific Popup, Font Awesome — всё через CDN или `wwwroot/lib`
- Локализация: `ru` (по умолчанию), `es`, `en` заданы в `Program.cs` через `RequestLocalizationOptions`, но фактически используется только `ru` — контента на других языках нет. Не добавляй hreflang для es/en, пока реально нет переведённого контента.

## SEO-соглашения (обязательны для любой новой/изменённой страницы)

1. **Каждая страница должна задавать** в блоке `@{ }`:
   ```csharp
   ViewData["Title"] = "...";       // обязательно, уникальный, до ~60 символов
   ViewData["Description"] = "..."; // обязательно, до ~160 символов, с CTA/сутью
   ViewData["Keywords"] = "...";    // опционально, для блог-статей
   ```
   Сейчас **не заполнено** на: Home, Technical, Design — при правках добавить.

2. **Тайтлы:** формат `Конкретика по странице | Big Lava` (не «biglv» строчными — унифицировать с брендом из схемы).

3. **Изображения:** `alt` обязателен и содержателен (не `alt=""`). Сейчас 179 картинок с пустым alt — по мере правок конкретных вьюх заполняй тем, что реально на картинке/иконке.

4. **Структурированные данные (JSON-LD в `_Layout.cshtml`):** используй правильные ключи `@context` и `@type` (сейчас там баг: `"context"`/`"type"` без `@` — из-за этого разметка не читается поисковиками). Тип — `LocalBusiness`, при возможности расширить до `ProfessionalService` с полями `sameAs` (соцсети), `openingHours`, `priceRange`.

5. **Один `<h1>` на страницу**, соответствующий заголовку из Title/сути страницы. Не использовать `<h1>` для декоративных заголовков блоков — там `<h2>`/`<h4>`.

6. **Canonical:** добавить `<link rel="canonical" href="https://biglv.ru/...">` в `_Layout.cshtml` через `ViewData` или `IUrlHelper`, генерировать динамически по текущему пути.

7. **robots.txt / sitemap.xml:** должны лежать в `wwwroot/`, обновлять sitemap при добавлении новых страниц блога (генерация вручную или через middleware — на усмотрение).

8. **Блог-статьи:** каждая новая статья — отдельный Controller/View по аналогии с `DevAndroid`/`QuamDevelopMobili`, обязательны Title/Description/Keywords, ориентированные на конкретный коммерческий или информационный запрос (например: «сколько стоит разработка iOS-приложения», «разработка приложения для доставки»). Добавлять статью в `Views/Blog/Index.cshtml` и в sitemap.

## Дизайн-система (редизайн в стиле metalab.com)

- Все страницы используют только `wwwroot/css/ml.css` + `wwwroot/js/ml.js` (классы `ml-*`). Старые `style.css`, bootstrap, owl, AOS, Font Awesome в `_Layout.cshtml` больше не подключены.
- Шапка `_Header`, большой CTA `_Cta` и подвал `_Footer` выводит layout. CTA на странице отключается через `ViewData["HideCta"] = true`.
- Стили, уникальные для страницы, — в `@section Head { <style> … </style> }` с префиксом `.pg-<страница>-*`. В Razor `@media` пишется как `@@media`.
- Анимация появления: `data-reveal` на блоке или `data-reveal-stagger` на родителе.
- Страницы ошибок: `ErrorController` + `Views/Error/Status.cshtml` (подключено через `UseStatusCodePagesWithReExecute`).
